# 九州灵迹：节气守护者

一款以 **二十四节气、五行、山海经异兽、古代建筑、农耕文化、竹简篆刻、水墨青绿山水** 为背景的横版像素/国风动作冒险 Web Demo。

## 当前版本：春之印三关垂直切片

玩家从四位节气行者中选择一位，从桃源村出发，穿越雷竹林和水乡古道，收集铜钱与竹简，点亮节气碑，最终挑战春雷木魈并获得第一枚五行灵珠。

### 四位行旅者

1. **禾灵**（女 · 春木）：平衡型，稷镰三段连击；K 水灵·润泽可灭火护身，L 春木·万物生范围复苏。
2. **炎朔**（男 · 夏火）：爆发型，熔焰钺高伤连击；K 小暑·炎息燎原三段火浪，L 大暑·熔岩焚野火雨清场。
3. **疏桐**（女 · 秋金）：远程型，金叶轮与飞刃；K 白露·金风叶刃扇形投射，L 秋分·万叶归宗叶刃风暴。
4. **玄泓**（男 · 冬水）：坦克型，玄冰戟；K 大雪·玄冰护体生成护盾并冻结近身敌人，L 冬至·寒泉归海全场凝霜。

### 关卡

1. **立春·桃源村**：学习移动和跳跃；收集铜钱；避开竹刺；击败山猪精；激活节气碑。
2. **惊蛰·雷竹林**：练习二段跳与藤蔓牵引；面对蜂妖、食人藤和落石；收集隐藏竹简；通过雷电机关。
3. **春分·水乡古道**：水流、木桥、升降平台；使用水灵关闭火焰机关；挑战春雷木魈；获得第一枚五行灵珠。

首版资产规模：**4 位主角（2男2女）、10 种敌人数据、3 种陷阱、3 个关卡、1 个 Boss、1 套中国风 UI、1 个结算画面**。

## 核心操作

- `A/D` 或方向键：移动
- `Space`：跳跃（二段跳）
- `J`：当前角色的三段连击
- `K`：当前角色的五行技能（灭火/火浪/飞刃/冰盾）
- `L`：当前角色的五行绝技（消耗满灵气）
- `Shift`：闪避
- `Esc`：暂停

移动端会显示虚拟摇杆和动作按钮。

## 技术实现

- **Vite + JavaScript**：快速开发和静态发布。
- **Three.js**：正交镜头、背景分层、Q版2.5D 立体图集角色、全角色地面阴影、粒子、残影、冲击环、Bloom、色调后期。
- **Planck.js**：重力、平台、角色碰撞和简单物理反馈。
- **数据驱动关卡**：`src/levels.js` 集中管理节气、长度、平台、波次、收集物、陷阱和 Boss 节点。
- **资源生成**：背景、UI 和音乐均可通过本地生成脚本接入用户提供的图片/音乐 API；四位角色图集由 `gpt-image-2` 生成并经 `tools/repack-character-atlas.py` 重排为严格 4×3；密钥只从 `.env.local` 读取。

详细设计与实现映射见 [`docs/IMPLEMENTATION.md`](docs/IMPLEMENTATION.md)。

## 本地开发

```bash
npm install
npm test
npm run build
npm run dev
```

> 若受限环境不允许 Vite 清理既有 `dist/`，可使用 `npx vite build --configLoader runner --outDir /tmp/jiuzhou-dist` 做构建验证。

## QA 入口

开发环境支持：

- `?qa=1` / `?qa=2` / `?qa=3`：直接进入三关
- `&wave=4`：跳过至指定波次
- `&bossHp=0.12`：缩短 Boss 回归时间
- `&god=1&energy=100`：战斗回归快捷参数
