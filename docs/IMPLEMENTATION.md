# 《九州灵迹：节气守护者》实现说明

## 目标

本版本不是一次性做完 18 关，而是先交付一个可玩的春季垂直切片：

`开始游戏 → 故事卷轴 → 横版移动/跳跃 → 战斗 → 收集 → 检查点 → 节气碑 → Boss/结算`

技术栈为 **Vite + Three.js + Planck.js**：Three.js 负责正交镜头、背景分层、像素/图集角色、粒子和后期；Planck.js 负责角色、平台、碰撞和重力；关卡内容全部数据化，后续扩展二十四节气时不需要重写主循环。

## 文化系统如何落地

- **二十四节气**：三关分别对应立春、惊蛰、春分；每关故事、颜色、背景、机关、Boss 目标和节气碑都由 `src/levels.js` 配置。
- **五行**：禾灵的 K 技能是“水灵·润泽”，L 技能是“春木·万物生”；第三关的火焰机关只能用水灵关闭，结算获得第一枚“五行灵珠”的叙事反馈。
- **山海经**：10 种敌人数据统一在 `src/actors.js`，先启用山猪精、蜂妖、食人藤等春季敌人，保留完整图鉴以便后续关卡复用。
- **古代建筑/农耕文化**：关卡背景采用桃源村、雷竹林、水乡古道语义；平台类型、节气碑、竹简、铜钱和机关用程序化几何叠加在生成背景上，避免背景图抢掉玩法可读性。
- **竹简篆刻**：竹简是可选收集物，节气碑是终点交互物；UI 采用卷轴、朱砂、青绿和玉石色。
- **水墨青绿山水**：背景为生成式山水图，运行时再叠加雾、云、星尘和 Bloom，形成远景/中景/玩法层三层空间。

## 三关实现映射

| 关卡 | 教学 | 机关/收集 | 战斗节奏 | 通关条件 |
|---|---|---|---|---|
| 立春·桃源村 | 移动、跳跃、普攻 | 铜钱、竹刺、检查点 | 山猪精/蜂妖/食人藤分波 | 击退全部敌人并激活节气碑 |
| 惊蛰·雷竹林 | 二段跳、藤蔓牵引的叙事化表现 | 隐藏竹简、落石、雷纹提示 | 远程蜂妖与重型石敢当混编 | 清空波次并激活节气碑 |
| 春分·水乡古道 | 水灵灭火 | 水流/木桥语义、火焰机关、升降节奏 | 水魈、火鼠、木魅，最后春雷木魈 | Boss 战后激活节气碑并结算五行灵珠 |

当前平台和机关是轻量程序化版本：平台使用固定碰撞体，陷阱以数据驱动并按关卡周期生成；这样比直接把整张背景当碰撞图更适合快速调关。后续如果需要更强的二段跳/藤蔓牵引，可在 `updatePlayer` 增加 `woodGrip` 状态和可攀附节点，不影响现有数据结构。

## 资源与音频策略

- 复杂关卡背景：使用 `gpt-image-2` 生成，再放入 `public/assets/backgrounds/jiuzhou-*.webp`。
- 主角图集：`gpt-image-2` 生成原始十二格图集后，由 `tools/repack-heling-atlas.py` 按内容边界裁剪并重排为 1024×768 严格 4×3，避免生成模型偶发多行/留白导致运行时精灵错位。
- 简单 UI/肖像补充：使用 MiniMax `image-01` 与 Qwen Image 生成，密钥只通过 `.env.local` 读取，绝不写入客户端 bundle。
- 音乐：使用 MiniMax `music-2.6` 生成 `jiuzhou-theme.mp3` 与 `jiuzhou-boss.mp3`。
- 出招音效：复用本地古风打斗素材包，经 `tools/import-combat-audio.py` 做裁切、限幅和 MP3 转码；`src/audio.js` 按普攻、技能、Boss、受击分层播放，并保留程序化兜底音效。
- A872 Spine 特效素材：当前只作为动作节奏与特效方向参考，运行时主要使用 Three.js 粒子、斩击弧光、冲击环、残影和 Bloom，避免把不可再分发的原始包提交到公开仓库。

## 运行与 QA

```bash
npm install
npm test
npm run build
npm run preview
```

开发环境提供 QA 参数：

- `?qa=1` / `?qa=2` / `?qa=3` 直接进入指定关卡
- `&wave=4` 跳到指定波次
- `&bossHp=0.12` 缩短 Boss 回归时间
- `&god=1` 开启无敌
- `&energy=100` 设定满能量
